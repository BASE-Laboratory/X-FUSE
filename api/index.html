    API Reference¶

    High-Level & Compositional 2D Fusion (x_fuse.fusion, x_fuse.heads)¶

    x_fuse.fusion ¶

    Compositional physics-guided foundation-model feature fusion engine CorrelativeFuser (aliased as XFuse).

    v1.0 Compositional Architecture: - self.backbone (HighResBackbone): Frozen ViT feature extractor with optional ApositionalFeatureDebiaser and CrossAttentionFeatureUpsampler (interpolation_mode="cross_attn") or JointBilateralUpsampler ("jbu"). - self.head (LinearProbeHead | SpatialConvMLPHead or WindowedGuideCrossAttentionHead): Composable fusion/prediction head coupled to PhysicsForwardModel (supporting Poisson shot-noise deviance NLL, simplex compositional KL, forward-PSF BCE/MSE, and raw 3D spectral/diffraction cube NMF unmixing). - self.guide_aligner (DifferentiableGuideAligner): Translation, rigid, affine, or cubic B-spline deformable scan-distortion registration. - self.calibrator (ConformalCalibrator): Optional finite-sample Split Conformal Prediction calibrator producing (1 - alpha) phase sets.

    XFuse = CorrelativeFuser module-attribute ¶

    CorrelativeFuser ¶

    Bases: Module

    Compositional correlative fusion solver combining a HighResBackbone, optional ApositionalFeatureDebiaser, CrossAttentionFeatureUpsampler / JointBilateralUpsampler, pluggable FusionHead + PhysicsForwardModel, DifferentiableGuideAligner (including cubic B-splines), and finite-sample ConformalCalibrator.

    clear_feature_cache() ¶

    Release any cached frozen TTA feature tensors.

    unmixed_spectra() ¶

    Return learned (M, E) spectral basis when unmixing is active.

    reset_trainable_weights() ¶

    Reset all specimen-specific trainable head, upsampler, aligner, and physics parameters (plus Adam momentum state) before fitting a new sample.

    set_guide_transforms(guide_tensor, fwd, inv, *, n_components=None, spectral_unmix=None) ¶

    Bind a (1, M, H_lr, W_lr) physical guide tensor (or 3D spectral cube (1, E, H_lr, W_lr) when spectral_unmix=True) and TTA views.

    set_xrd_transforms(xrd_tensor, fwd, inv) ¶

    Backward-compatible alias for set_guide_transforms.

    forward_raw_features(x, attn_choice='none') ¶

    Extract dense TTA-averaged ViT features (1, C, H, W) without guide modulation (delegating directly to self.backbone_extractor).

    forward(x, attn_choice='none', top_k=None) ¶

    Standard nn.Module.forward entrypoint: runs guide-modulated TTA fusion if a guide has been bound, else returns raw TTA ViT features.

    forward_sequential(x, attn_choice='none', top_k=None) ¶

    Run TTA-ensembled feature extraction + guide fusion.

    forward_with_variance(x, attn_choice='none', top_k=None) ¶

    Run TTA-ensembled feature extraction + guide fusion while tracking online Welford spatial variance across transforms in O(1) extra memory.

    train_fusion_step(x, update_aligner=True, valid_hr_hw=None, loss_mask_lr=None, pore_mask_hr=None) ¶

    Optimize the active fusion head (+ optional trainable cross-attention upsampler, DifferentiableGuideAligner, learnable PSF, and spectral dictionary) across all TTA views in canonical HR coordinate space while keeping the ViT frozen.

    predict_with_uncertainty(x, guide_lr=None, mode='multilabel', calibrate_to_guide=True, abstain_threshold=None, top_k=None, *, unguided_transfer=False, use_aligner=True, valid_hr_hw=None, pore_mask_hr=None) ¶

    Produce calibrated high-resolution phase/element probabilities, tri-part pixel certainty, and optional Split Conformal prediction_sets.

    fit(hr_image, coarse_guide, epochs=25, tta_shifts=(1,), tta_flips=True, warmup_fraction=0.3, guide_normalization=None, n_components=None, spectral_unmix=False, *, pore_mask=None, max_steps=None, tol=1e-06, reset_weights=True) ¶

    High-level training entrypoint: normalizes and pads hr_image and coarse_guide (or raw 3D spectral cube when spectral_unmix=True), caches frozen ViT TTA features, optimizes the fusion head (+ optional co-registration, PSF width, & spectral dictionary), and calibrates out-of-sample Split Conformal prediction sets when conformal_alpha is set.

    predict(hr_image, coarse_guide=None, mode='auto', calibrate_to_guide=True, abstain_threshold=None, top_k=None, guide_normalization=None, *, pore_mask=None) ¶

    High-level inference entrypoint: predicts calibrated probabilities and an UncertaintyReport automatically cropped back to hr_image shape.

    fit_predict(hr_image, coarse_guide, epochs=25, mode='auto', tta_shifts=(1,), tta_flips=True, calibrate_to_guide=True, abstain_threshold=None, guide_normalization=None, n_components=None, spectral_unmix=False, *, pore_mask=None, max_steps=None, tol=1e-06, reset_weights=True) ¶

    Fit the fusion model on (hr_image, coarse_guide) and return the calibrated, un-cropped UncertaintyReport in a single call.

    segment_pores_otsu(high_res, *, tie_homogeneity_alpha_vox2=0.0, detrend_cupping=False, roi_mask=None, dark_pores=True) ¶

    Derive a boolean structural void/pore mask M_pore from a 2D (H, W) micrograph or 3D (Z, Y, X) tomogram without blurring high_res itself.

    When tie_homogeneity_alpha_vox2 > 0 (e.g. 0.6), applies a Fourier Tie-homogeneity phase-retrieval filter solely to compute a Fresnel-fringe-free segmentation threshold, preventing bright/dark Ram-Lak edge overshoots from punching false pinholes in solid walls or leaving 1-px chemical shells in pores.

    compute_channel_correlation_gates(features, guide_map, loss_fn='pearson', top_k=None) ¶

    Vectorized per-channel relevance gates (M, C) between features (B, C, H, W) and guide_map (1, M, H_lr, W_lr) without Python loops.

    x_fuse.heads ¶

    Composable high-resolution fusion and phase-prediction heads for X-FUSE:

    1. LinearProbeHead (aliased as LearnedChannelGating): Fast pixel-wise linear projection + channel ranking supervised via PhysicsForwardModel.
    2. SpatialConvMLPHead (fusion_method="spatial_mlp"): Nonlinear bottleneck MLP + 3x3 depthwise-separable spatial context residual + multi-scale HR texture skip connection + optional edge-aware Total Variation regularization.
    3. WindowedGuideCrossAttentionHead (aliased as XRDCrossAttention / SpatialCrossAttention): Memory-safe O(H * W) pooled-key cross-attention replacing the legacy O((H * W)^2) global attention bottleneck so 512x512+ micrographs run in < 80 MB RAM.

    LinearProbeHead ¶

    Bases: Module

    Linear probe ranking ViT channels by physical guide relevance and predicting calibrated HR logits supervised through PhysicsForwardModel.

    predict_logits(features, guidance_hr=None) ¶

    Predict (B, M, H, W) phase/element logits directly from features.

    get_channel_importance() ¶

    Return (C,) channel importance aggregated across all M outputs.

    SpatialConvMLPHead ¶

    Bases: Module

    Nonlinear spatial fusion head (fusion_method="spatial_mlp") combining ViT semantic features with multi-scale HR texture & anisotropy coherence descriptors via a bottleneck residual depthwise-separable Conv-MLP block and optional spin-2 edge-aware TV prior.

    apply_guide_residual(logits_canon, canon_guide, valid_hr_hw=None) ¶

    Anchor canonical structural logits to the smooth coarse-guide prior so macroscopic intra-grain chemical zonation invisible in I_HR is preserved while SpatialConvMLPHead learns high-frequency boundary deconvolution.

    WindowedGuideCrossAttentionHead ¶

    Bases: Module

    Memory-safe O(H * W) pooled-key cross-attention head replacing the legacy O((H * W)^2) global attention bottleneck.

    Caps the spatial key/value token grid to at most max_kv_grid x max_kv_grid (default 16 x 16 = 256 tokens) via adaptive average pooling and blends the attended semantic tokens with a local 3x3 residual feature skip, running comfortably on 512x512–2048x2048 micrographs in < 80 MB RAM.

    forward(features, xrd_map) ¶

    Modulate features (B, C, H, W) in O(H * W * K_pool) memory.

    edge_aware_tv_loss(logits, guidance_hr=None, edge_beta=10.0, simplex=False, orientation_aware=True) ¶

    Anisotropic edge-aware Total Variation prior on HR logits (B, M, H, W). Smooths noisy sub-patch predictions inside homogeneous grains while relaxing smoothing across strong structural intensity, texture, or spin-2 orientation boundaries in I_HR.

    Quantitative Forward Physics & Spectral Unmixing (x_fuse.physics)¶

    x_fuse.physics ¶

    Quantitative physical forward operators, likelihood losses, and raw 3D spectral/diffraction cube unmixing for correlative materials imaging.

    Supports: 1. SpectralUnmixingDictionary: Non-negative endmember spectral/diffraction dictionary S in R_+^(M x E) initialized via deterministic multiplicative NMF and refined end-to-end against raw (E, H_lr, W_lr) data cubes. 2. PhysicsForwardModel: Unified physical forward operator Lambda_LR = tau * D_Sigma(W_phi(P_HR)) @ S + b with: - Exact Poisson shot-noise deviance negative log-likelihood ("forward_psf_poisson") for low-count EDS, EELS, and fast XRD-CT. - Simplex-constrained compositional phase-fraction conservation ("compositional_kl", guaranteeing sum_k P_k(x) = 1 at every pixel). - Partial-volume "forward_psf_bce", "forward_psf_mse", "bce", and "pearson" objectives.

    PhysicsForwardModel ¶

    Bases: Module

    Unified physical forward model mapping HR logits (B, M, H, W) to coarse measurements G_LR (B, M, H_lr, W_lr) or 3D spectral cubes Y_LR (B, E, H_lr, W_lr) via anisotropic PSF integration, spatial drift alignment, flux/background scaling, and optional spectral mixing.

    reset_specimen_state() ¶

    Reset data-dependent scale and simplex flags before fitting a new sample.

    maybe_initialize_poisson_scale(target, mask_lr=None) ¶

    Initialize log_flux_scale and raw_background from target count quantiles on the first training call so optimization starts at physical scale.

    logits_to_simplex_probs(logits, target=None) ¶

    Convert HR logits (B, M, H, W) to exact simplex probabilities summing to 1.0 along channel dimension 1 (either (B, M+1, H, W) with channel 0 = matrix/background, or (B, M, H, W) when complete).

    forward_coarse_prediction(logits, lr_hw, aligner=None, target_hint=None, valid_hr_hw=None) ¶

    Map HR logits (B, M, H, W) through spatial alignment, physical PSF integration, and optional spectral dictionary mixing.

    compute_loss_from_logits(logits, guide_map, coarse_target=None, aligner=None, valid_hr_hw=None, loss_mask_lr=None) ¶

    Evaluate the configured physical objective between HR/patch logits and coarse_target (or guide_map), cropping divisibility padding via valid_hr_hw and excluding conformal holdout pixels via loss_mask_lr.

    diagnostics(hr_hw, lr_hw) ¶

    Return physical forward-model diagnostics (PSF widths, flux, basis).

    SpectralUnmixingDictionary ¶

    Bases: Module

    Differentiable non-negative spectral/diffraction basis S of shape (n_components, spectral_channels) with unit-normalized rows (sum_e S_{m,e} = 1) so abundance maps preserve physical count scale.

    spectra() ¶

    Return row-normalized non-negative basis (M, E) summing to 1.

    initialize_from_cube(cube_lr, n_iters=40, seed=0) ¶

    Decompose cube_lr (E, H_lr, W_lr) or (B, E, H_lr, W_lr) via multiplicative-update NMF, populate self.raw_spectra, and return initial coarse abundance maps (B, M, H_lr, W_lr).

    project_cube(cube_lr, n_iters=25) ¶

    Unmix a new ([B,] E, H_lr, W_lr) spectral cube against the fixed learned endmember basis self.spectra() via multiplicative NMF updates, returning (B, M, H_lr, W_lr) abundance maps.

    forward(abundances_lr) ¶

    Mix coarse abundances (B, M, H_lr, W_lr) with basis (M, E) into reconstructed spectral cube (B, E, H_lr, W_lr).

    poisson_deviance_loss(pred_rate, target_counts, eps=1e-06, mask_lr=None) ¶

    Exact non-negative Poisson Bregman deviance (shifted Poisson NLL): mean(pred - y * log(pred) - (y - y * log(y))) >= 0, achieving 0 iff pred == y and maintaining well-conditioned O(1) values across count regimes.

    x_fuse.debias ¶

    Apositional Vision Transformer feature debiasing to eliminate spatial coordinate-ramp shortcut learning on homogeneous micrographs and macroscopic chemical diffusion gradients.

    Motivated by recent findings on ViT positional leakage in electron/X-ray microscopy (e.g., DINO-SAW, Docherty et al., arXiv:2603.16840), frozen DINOv2, DINOv3, MAE, and SAM backbones contain channels that act as smooth (y, x) coordinate ramps. When supervising a probe with a coarse physical map exhibiting a macroscopic spatial gradient (e.g. core-shell catalyst pellet or battery electrode lithiation gradient), an un-debiased probe can overfit to coordinate-ramp channels instead of true grain morphology.

    ApositionalFeatureDebiaser removes spatial polynomial ramp components via: 1. Closed-form QR orthonormal spatial polynomial projection (r2_threshold=0.0 projects out (y, x) polynomials across all channels to machine precision; r2_threshold > 0 selectively detrends or attenuates ramp-dominated channels), or 2. Content-free noise/flip calibration (calibrate_from_backbone), identifying intrinsic ViT positional channels on isotropic white noise so genuine sample-level microstructural density gradients remain completely untouched.

    Bases: Module

    x_fuse.uncertainty ¶

    Pixel- and voxel-level uncertainty quantification, calibration, physical forward-model consistency diagnostics, and finite-sample Split Conformal Prediction sets for correlative materials fusion.

    Provides four complementary uncertainty & statistical guarantee mechanisms: 1.
